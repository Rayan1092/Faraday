# dashboard/

**Owner: Dell laptop.**

This is the local web page the app serves at `http://127.0.0.1:8080` (port from settings). It needs to be big and readable on a projector. It shows the current mode, the live event log, the latest photo and description, saved messages and rules. It also has a text box fallback for speech and a passphrase box. No internet, CDNs or web fonts.
