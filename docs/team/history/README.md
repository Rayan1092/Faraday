# Team history (handoffs)

**Leave a handoff note here after every task**, before you push, so the other laptop (or the next Claude session) can pick up without asking.

File name: `YYYY-MM-DD-HHMM-<nv|dell>-<short-task>.md`, for example `2026-11-14-1730-nv-flipper-rx.md`.

Template:

```markdown
# <task>
- Laptop / branch / PR:
- What changed:
- How it was tested: real hardware / sim / stand-in (only real hardware signs off)
- What works:
- What's broken or faked:
- Next step:
- Open Questions added to PLAN.md:
```

Keep it short, five to ten lines is plenty.
