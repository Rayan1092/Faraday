- What works:
  - Lights, photos and warning/alarm happen before Bonsai is asked.
  - "One moment, please." goes out before each visitor call.
  - Bonsai repeats are dropped (`1 already done`).
  - Spoken "Blue pelican 17." disarms and resets the alert.
  - If Bonsai saves a message without speaking, code adds "Thank you. I saved your message."
  - The reply after `photo_described` is traced through `caused_by`:
    - A doorbell photo gets a greeting and an offer to take a message. Code adds the offer if Bonsai leaves it out.
    - A motion photo while armed always gets "You're on camera. The owner has been alerted." in plain code.
  - Motion is now fully plain code with no Bonsai call. It used to cause a second, odd greeting and 6–12 s of blocking.
  - The disarm refusal is now "I can't disarm. Only the owner can do that." and no longer mentions the passphrase.

  - User rules from `add_rule` aren't stored or fired yet, so demo step 5 (lamp too) doesn't work yet.
  - `summarize_log` isn't run yet.
