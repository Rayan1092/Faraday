# Faraday

An offline AI home guard. It runs on one Mac mini with Wi-Fi off and uses a Flipper Zero (433 MHz doorbell, motion sensor, outlets), a camera, a mic, a speaker, Bonsai 2 in LM Studio and Argmax speech.

Start with [CLAUDE.md](CLAUDE.md), then [docs/PLAN.md](docs/PLAN.md) and [docs/FORMATS.md](docs/FORMATS.md).

```
pip install -r requirements.txt
cp config/settings.example.json config/settings.json   # then edit
```
